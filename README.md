# LOBBY SCREENS

מוצר שילוט דיגיטלי למסכי לובי בבנייני מגורים (יעד: מסך ~40 אינץ', רזולוציית טלוויזיה). בהשראת מוצרים קיימים בשוק (dlobby.co.il, מסך NYMEDIA שאביב צילם בבניין אמיתי) — אבל בכיוון עיצובי ותוכני משלנו.

## סטטוס נוכחי (9.8.2026)

שלב **מוקאפ עיצובי ראשוני**. עברנו כמה סבבים של כיוון עיצובי (ראו "היסטוריית החלטות" למטה) והגענו למבנה שאביב אישר ברמת השלד. עדיין לא נבנה שום דבר בפרודקשן — הכול HTML/CSS סטטי לצורך הצגה.

**המוקאפ העדכני ביותר**: `mockups/v6-current.html` — פתחו בדפדפן ישירות (קובץ עצמאי, כולל את כל התמונות מוטמעות).

## תוכן המסך (מה שהוגדר עד כה)

- **כניסת שבת** — זמן הדלקת נרות ופרשת השבוע, כולל טבלת זמנים ל-5 ערים בארץ.
- **מזג אוויר** — תחזית 3 ימים.
- **חדשות Ynet** — סרגל תחתון רץ, עם לוגו רשמי.
- **ספורט ONE** — סקשן עם כותרות אמיתיות, תמונה, ולוגו רשמי.
- **פרסום עסקים** — placeholder, פיצ'ר עתידי בלבד.
- **שעון + פרטי הבניין** — עם תמונת הבניין האמיתית (נחל חבר 16-18, באר שבע).

|---|---|---|

| **Ynet** (חדשות) | ✅ עובד | RSS חי: `https://www.ynet.co.il/Integration/StoryRss2.xml`. הפיד הראשי כולל חדשות קשות (פשע/ביטחון) לצד תוכן ניטרלי — נדרש סינון/קיוריישן לפני תצוגה בלובי. ניסינו פיד קטגוריה נפרד (StoryRss3086) אך התברר כאנגלית (Ynetnews) ולא רלוונטי. |
| **ONE.co.il** (ספורט) | ✅ עובד, ומצוין | RSS רשמי ומוצהר: `https://www.one.co.il/rss`. **כולל תמונה אמיתית לכל כתבה** (`<media:content>`). 50+ פריטים מתעדכנים. לוגו רשמי: `https://images.one.co.il/images/msites/2017/01/24/apple-touch-icon-180x180.png`. |
| **Sport5** (ספורט) | ❌ לא נמצא | נבדקו כל נתיבי ה-RSS הסבירים (404/500), אין `<link rel="alternate">` בעמוד הבית. אין API ציבורי גלוי. |
| **IMS** (מזג אוויר רשמי) | ⚠️ לא נבדק לעומק | קיים API רשמי אך מיועד בעיקר לנתוני תחנות גולמיים, לא תחזית מוכנה. חלופה: ספק גלובלי (OpenWeatherMap וכו'). |

**מגבלה חשובה**: כל המקורות דורשים משיכה בצד שרת (PHP/Node וכו') — לא ניתן למשוך RSS/API חיצוני ישירות מהדפדפן בגלל CORS, ולא בתוך ארטיפקט מקוד סגור (CSP חוסם fetch לדומיינים חיצוניים). בפרודקשן זה נפתר בקלות עם endpoint צד-שרת שממשוך ומקאש.

## היסטוריית החלטות עיצוביות

1. **ניסיון ראשון** — פלטת "דמדומים" כהה עם זהב, בהשראת מסכי digital signage מקצועיים. **נדחה**: "נראה כמו האפליקציה של פיפא לוטרי" (ראו `../fifa-lottery` בתיקיית הפרויקטים — זו הייתה השוואה קונקרטית, לא מליצית).
2. **בקשה ל-WordPress** — אביב ביקש שהמימוש הסופי יהיה על וורדפרס (לא ארטיפקט סטטי). הסביבה הנוכחית לא כוללת PHP/וורדפרס מותקן — זה עדיין baclog לשלב הבא. המוקאפים הנוכחיים הם HTML/CSS עצמאי שניתן להדביק כ-Custom HTML בעמוד וורדפרס אמיתי.
3. **תמונת ייחוס אמיתית** — אביב שלח צילום מסך אמיתי של מסך מותקן בבניין (ספק בשם NYMEDIA, בבאר שבע). זה קבע את המבנה: אזור "קרוסלה" גדול מצד שמאל (מתחלף), סיידבר קומפקטי מצד ימין (שעון/מזג אוויר/הודעות), סרגל Ynet קבוע בתחתית. המבנה הזה אושר ונשמר מאז.
4. **תיקוני באגים אמיתיים בדרך** (לא רק העדפה אסתטית):
   - RTL grid blowout — עמודת ה-grid החיצונית לא הוגדרה מפורשות, מה שגרם לתוכן טקסט בתוך שכבה position:absolute "לדלוף" ולנפח את הרוחב לכפול מהמסך. תוקן במעבר ל-flex בשכבה החיצונית.
   - RTL marquee gap — טכניקת ה-"שני עותקים + translateX(-50%)" לסרגל חדשות עובדת מושלם ב-LTR אך יוצרת פער גדל בהדרגה ב-RTL (הוכח מתמטית). הפתרון: `direction:ltr` מקומי רק על אלמנט הסרגל עצמו.
   - תמונות חיצוניות מקושרות (hotlink) עובדות בבדיקה מקומית אך **נחסמות ע"י ה-CSP של הארטיפקט בפרודקשן** — כל התמונות חייבות Base64 מוטמע.
